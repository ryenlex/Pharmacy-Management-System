# Pharmacy Management System

Python desktop application focused on improving usability.

## Current features
- Dashboard overview
- Medicine management (add, edit, delete)
- Search and category/stock filters
- Calendar for expiry-date viewing
- Dark mode
- Custom themes
- SQLite database

## Run in VS Code

1. Open this folder in VS Code.
2. Create a virtual environment:
   `python -m venv venv`
3. Activate it on Windows:
   `venv\Scripts\activate`
4. Install packages:
   `pip install -r requirements.txt`
5. Run:
   `python main.py`

The SQLite database file is created automatically in `database/pharmacy.db`.
